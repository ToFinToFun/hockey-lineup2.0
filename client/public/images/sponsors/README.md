# Sponsorloggor

Används i matchbandet på laget.se-nyheten ("Nyhet till laget.se" i Lineup).

- Filnamn: sponsorns namn i gemener, å/ä/ö → a/o, mellanslag → bindestreck, `.png`.
  Exempel: `Polar` → `polar.png`, `Lindström Transport` → `lindstrom-transport.png`.
- Bakgrunden är mörk: använd en ljus eller transparent variant.
- Saknas filen skrivs sponsorns namn ut i stället.
